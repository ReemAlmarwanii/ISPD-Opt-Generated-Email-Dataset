# ISPD-Opt Author-Generated Email Subset v1.0

This release provides the exact screened author-generated half of the benchmark used in **Intent-Style Evaluation of Machine-Generated Phishing Email Detection**.

Citable dataset DOI: <https://doi.org/10.5281/zenodo.22336828>.

## Release contents

- 1,800 records and 32 fields.
- 900 machine-generated legitimate records (GL).
- 900 machine-generated phishing records (GP).
- 800 ChatGPT, 800 Claude, and 200 Gemini records.
- No human-written legitimate or phishing records.
- No reconstructed external-source email text.
- CSV SHA-256: `af7c858690f8e6286d9618e96abc98ecb96815a2a2cbe4738faa0706c8ab190e`.

The released text values are byte-for-byte unchanged from the verified source benchmark. See `RELEASE_AUDIT.json`, `DATA_DICTIONARY.md`, and `SHA256SUMS.txt` for integrity, composition, and safety details.
