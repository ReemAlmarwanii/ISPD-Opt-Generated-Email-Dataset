
# ISPD-Opt Author-Generated Intent--Style Email Subset

Version 1.0 (2026-09-04). Citable dataset DOI: <https://doi.org/10.5281/zenodo.22336828>. Maintained repository: <https://github.com/ReemAlmarwanii/ISPD-Opt-Generated-Email-Dataset>.

This deposit-ready dataset contains the 1,800 email records generated by the author for the study **Intent--Style Evaluation of Machine-Generated Phishing Email Detection**: 900 machine-generated legitimate records (GL) and 900 machine-generated phishing records (GP). It contains 800 ChatGPT, 800 Claude, and 200 Gemini records in total.

The released `text` values are byte-for-byte unchanged from the verified 3,600-record benchmark. Their stored SHA-256 values were recomputed successfully for all 1,800 rows. No human-written legitimate or phishing text (HL/HP), reconstructed external-source text, embedding cache, or internal source-file path is included.

The messages were created for controlled defensive evaluation and were not sent, deployed, or directed at real recipients. Operational links and attachments are represented only by `[SAFE_PORTAL_URL]` and `[SAFE_ATTACHMENT]`. The automated release audit found no email address, live URL, internet domain, IP address, private-key header, common API token, payment-card candidate, phone candidate, or active HTML form/script/iframe.

## Files

- `ISPD_Opt_Author_Generated_Email_Subset_v1.0.csv`: exact generated subset and associated metadata.
- `DATA_DICTIONARY.md`: field definitions.
- `RELEASE_AUDIT.json`: source fingerprint, composition, integrity checks, and automated safety scan.
- `CITATION.cff`: machine-readable citation metadata for the released Zenodo dataset record.
- `LICENSE.md`: Creative Commons Attribution 4.0 International licence notice.
- `.zenodo.json`: deposit metadata for an open dataset record.
- `GITHUB_RELEASE_NOTES_v1.0.md`: versioned release summary suitable for the GitHub release page.
- `SHA256SUMS.txt`: integrity hashes for all files other than the checksum file itself.

## Reproducibility boundary

This subset supports independent inspection and rerunning of analyses involving the author-generated records. A complete reconstruction of the 3,600-record benchmark additionally requires lawful access to the named third-party human-email corpora and the reconstruction documentation supplied with the manuscript's reproducibility package.

## Responsible-use statement

The author asks users to limit use to legitimate research, education, defensive security evaluation, and reproducibility. The examples should not be sent to real recipients or used to impersonate real entities, collect credentials, or facilitate fraud or abuse.
